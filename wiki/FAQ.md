# FAQ

**Is it official?** No. It's a community project, not affiliated with Anthropic.

**Is it free?** Yes — MIT licensed, forever.

**Is it safe?** It only talks to `api.anthropic.com` and has no telemetry. See [Privacy and Security](Privacy-and-Security).

**Does it work with Max / Team plans?** It reads whatever the usage endpoint returns for your account; Pro is the tested case.

**Why isn't it in the App Store / notarized?** Notarization needs a paid Apple Developer account. It's on the [roadmap](Roadmap).

**The mascot looks like Claude Code's character.** It's an homage in a free, open-source project. If Anthropic ever asks, we'll change the design.

**Will it break?** The usage endpoint is undocumented, so possibly — see [Undocumented API](Undocumented-API). A local-log fallback is planned.

**Windows/Linux?** Not planned — it's native SwiftUI. Ports are welcome as separate projects.
