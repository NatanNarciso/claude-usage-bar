# Code of Conduct

This project follows the [Contributor Covenant v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be kind, assume good intent, keep feedback constructive, and no harassment or discrimination of any kind. Report problems privately via a GitHub security/contact channel on the maintainer's profile; maintainers may remove content or ban participants who violate these standards.
